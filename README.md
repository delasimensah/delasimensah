## 🧭 How I work

1. **Requirements first.** I find out what's really needed, then look for the simplest thing that works reliably.
2. **Small, tested changes.** One ticket, one change, with tests.
3. **AI as a fast pair.** I read and run every line it writes, and I make the decisions.
4. **Test with real users.** I put each piece in front of the person who'll use it and fix what confuses them.

New stack? I get productive quickly with AI as a pair, and I'm straight about what I don't know yet.
